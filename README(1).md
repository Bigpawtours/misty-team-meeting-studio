# Misty’s Team Meeting Studio

A polished, shareable facilitation tool for Keller Williams Realty Professionals team meetings and workshops.

## Featured Workshop

### Keeping It Together: Home Inspection Negotiation Lab

A 30–45 minute interactive workshop designed for 10–15 agents.

Agents are split into Buyer and Seller teams and receive different information about the same transaction. Each side prepares its client strategy, negotiates live, receives a curveball, and debriefs the outcome.

The goal is to practice:

- Client counseling
- Inspection prioritization
- Negotiation strategy
- Seller disclosure awareness
- Information control and leverage
- Keeping a workable transaction together

## Publish with GitHub Pages

1. Create a GitHub repository named `misty-team-meeting-studio`.
2. Upload:
   - `index.html`
   - `house-tour.mp4`
   - `README.md`
3. Open the repository’s **Settings**.
4. Select **Pages** in the left sidebar.
5. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Click **Save**.
7. GitHub will generate a public URL for the studio.

It will typically look like:

`https://YOUR-USERNAME.github.io/misty-team-meeting-studio/`

## Workshop Note

The property video is used as visual context for the exercise. Inspection findings, disclosures, repair estimates, pricing, and confidential client information inside the simulation are fictional training materials.

For real transactions, agents should rely on current contracts, forms, licensed professionals, and managing-broker guidance.
